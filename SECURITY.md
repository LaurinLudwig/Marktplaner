# Sicherheit

Der Marktplaner arbeitet offline, hat keinen Server und kein Konto. Sicherheitsrelevant sind vor allem das Öffnen
fremder Projektdateien (`.mplan`/`.schelme`) und importierter Hintergrundpläne (PDF, SVG, Bilder).

## Unterstützte Versionen
Sicherheitskorrekturen gibt es für die jeweils neueste Version unter
[Releases](https://github.com/LaurinLudwig/Marktplaner/releases/latest) und für die Browser-Version.

## Lücke melden
Bitte **kein öffentliches Issue** anlegen. Melde die Lücke vertraulich über
[„Report a vulnerability“](https://github.com/LaurinLudwig/Marktplaner/security/advisories/new) im Reiter
„Security“ des Repos. Hilfreich sind betroffene Version, Betriebssystem, Schritte zum Nachstellen und, falls
möglich, eine Beispieldatei.

Du bekommst in der Regel innerhalb von zwei Wochen eine Rückmeldung. Das Projekt wird in der Freizeit betreut;
eine Belohnung gibt es nicht.
